## Genome size and a short plastome summary.

The selected genome is the complete chloroplast genome of *Zea mays*. It is **140,384 bp long** and has a **circular** topology.

The genome has the common **LSC–IR–SSC–IR** organization:

- **LSC (Large Single-Copy):** 82,355 bp
- **SSC (Small Single-Copy):** 12,536 bp
- **IR (Inverted Repeat):** 22,748 bp each

The Galaxy analysis showed that the genome contains **1 sequence record** and has a **GC content of 38.46%**. :contentReference[oaicite:2]{index=2}

## A short description of how the genome was downloaded and uploaded to Galaxy.

The complete *Zea mays* chloroplast genome was obtained from the NCBI Nucleotide/RefSeq database using accession **NC_001666.2**.

The genome sequence was downloaded in **FASTA format** and uploaded to **UseGalaxy.org**. The FASTA file was then analyzed using the **Fasta Statistics** tool to obtain the genome length, number of sequence records, nucleotide counts, and GC content.

The annotated GenBank/RefSeq record was used to examine genes, introns, pseudogenes, and other genomic features. :contentReference[oaicite:3]{index=3}

## Gene Content and Important Observations

The Zea mays chloroplast genome contains 104 genes, including 70 protein-coding genes, 30 tRNA genes, and 4 rRNA genes. Important genes include rbcL, psaA, psbA, atpA, petB, rpoB, rpl16, and matK, which are involved in photosynthesis, energy production, gene expression, and chloroplast functions.

Important observations include the presence of intron-containing genes such as rpl2 and rpl16, the association of matK with the trnK intron, and duplicated genes within the inverted repeat (IR) regions. The genome also contains degenerated reading frames and gene fragments, reflecting changes that occurred during chloroplast genome evolution.

## Reproducibility

Another student can repeat this analysis by following these steps:

1. Go to [NCBI Nucleotide](https://www.ncbi.nlm.nih.gov/nuccore/).

2. Search for accession **NC_001666.2**.

3. Open the *Zea mays* chloroplast complete genome record.

4. Download the genome sequence in **FASTA format**.

5. Log in to [UseGalaxy.org](https://usegalaxy.org/).

6. Create a new Galaxy history.

7. Upload the FASTA file.

8. Run **Fasta Statistics**.

9. Record the genome length, number of sequence records, and GC content.

10. Use the annotated NCBI record to examine genes and other genomic features.

11. Document the results and screenshots in GitHub.

Using the same NCBI accession and Galaxy tool should allow another student to reproduce the basic sequence-statistics analysis.
